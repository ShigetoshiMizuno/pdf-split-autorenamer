## 更新ポリシー

- **SPEC.md**: 「決定事項のみ」を記述。新機能追加時は FR-N で追記し、削除されたものは取り消し線または別節に移す
- **PLAN.md**: バージョンの達成条件・進捗を更新
- **TODO.md**: タスクが完了したら `- [x]` にチェック、または完了済みセクションに移動
- **KNOWLEDGE.md**: コードを変更したら関連する記述も更新。「実装途上」の記述は完了したら更新する
