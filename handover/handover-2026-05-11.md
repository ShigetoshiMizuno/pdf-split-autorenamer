## Key Decisions & Rationale

- **バッチファイルのコメントは英語のみ**にする → 理由: Windows CMD.EXE は SJIS(cp932) 期待で、UTF-8 で日本語コメントを書くと `::` ラベル解釈失敗でクラッシュ。Claude Code の Write ツールは UTF-8 固定のため、英語コメントなら問題なし
- **SJIS で書きたいときは PowerShell 経由** → `[System.Text.Encoding]::GetEncoding('shift_jis')` で `[System.IO.File]::WriteAllText` する
- **nkf32 導入は見送り** → winget/choco に登録なし、手動 DL は費用対効果が低い。PowerShell で代替可能
- **Issue #24 にサンプル PDF・動作デモのサブタスクを統合** → 別 Issue にせず Phase 1（素材作成）/ Phase 2（HTML 作成）として 1 Issue にまとめた

## Blockers, Gotchas & Workarounds

- **バッチファイルの文字コード問題**
  - **原因**: CMD.EXE は SJIS 期待だが、Write ツールは UTF-8 で保存。日本語コメントが `::` ラベル解釈で失敗してバッチが即終了
  - **解決**: コメントは英語のみにする / PowerShell で SJIS 書き込み
  - **再現**: `Write` ツールで日本語コメント入り `.bat` を作成 → ダブルクリック起動するとウィンドウが一瞬で閉じる
- **Bash から explorer 直接起動が失敗**
  - **回避**: `powershell -Command "Start-Process explorer 'path'"` 経由なら成功

## Key Learnings & Gotchas (長期記憶へ移行推奨)

- Windows `.bat` 作成時は **SJIS 必須**。Write ツール（UTF-8）使用時はコメントを英語のみにすること
- PowerShell で SJIS ファイルを書く定型: `[System.IO.File]::WriteAllText($path, $content, [System.Text.Encoding]::GetEncoding('shift_jis'))`
- pythonw を使うとコンソールなしで GUI 起動可能（エラー時はサイレントフェイル）
